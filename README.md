# Compliance Reviewer

Compliance Reviewer is a Salesforce-native, metadata-driven framework for reviewing PDF documents against structured Salesforce data using Prompt Builder and generative AI.

The solution is distributed as a Salesforce Managed Second-Generation Package (2GP) under the `CGContrReviewer` namespace.

## How It Works

A user starts a review from a Salesforce record and selects a PDF stored in Salesforce Files.

Compliance Reviewer then:

1. Resolves the configured review scenario.
2. Locates the target Salesforce record and selected PDF.
3. Collects relevant Salesforce data using configurable Field Sets.
4. Builds a structured evidence packet.
5. Sends the PDF and evidence to a packaged Salesforce Prompt Template.
6. Parses the structured AI response.
7. Persists the result in `Compliance_Review__c` for auditability.

## Architecture

The solution is implemented on Salesforce Platform using:

- Apex
- Lightning Web Components (LWC)
- Custom Objects
- Custom Metadata Types
- Field Sets
- Permission Sets and Custom Permissions
- Salesforce Files
- Prompt Builder
- Salesforce ConnectApi

Main runtime components:

- `ComplianceAgentController` — UI entry point.
- `ComplianceAgentConfigurationProvider` — reads Custom Metadata and Field Set configuration.
- `ComplianceAgentResolver` — resolves records, relationships, fields, and available PDFs.
- `ComplianceAgentEvidenceBuilder` — builds the structured Salesforce evidence packet.
- `ComplianceAgentAnalyzer` — invokes the Prompt Template and persists the analysis result.

## Configuration

Compliance Reviewer is configured through:

- `Compliance_Agent_Setting__mdt`
- `Compliance_Agent_Context__mdt`

Field Sets determine which Salesforce fields are included in the evidence supplied to the Prompt Template.

This metadata-driven model allows the solution to support different Salesforce data models without modifying Apex.

## Review Results

Completed analyses are persisted as `Compliance_Review__c` records.

The review record stores information including:

- source and target records;
- reviewed Salesforce File;
- evidence payload;
- review status;
- discrepancy count;
- generated summary;
- structured analysis response.

## Prompt Template

The package includes:

`Compliance_Agent_Contract_Evidence_Analysis`

The template receives:

- the selected Salesforce PDF;
- the structured evidence JSON generated by Compliance Reviewer.

Apex invokes the template through Salesforce `ConnectApi`.

## Permissions

The package includes:

- `Compliance_Agent_User`
- `Compliance_Agent_Manager`
- Custom Permission `Compliance_Agent_Use`

Administrators must also provide users with the Salesforce object, field, and file access required by their configured review scenarios.

## Prerequisites

The subscriber org must support and have enabled the Salesforce Prompt Builder / Einstein generative AI capabilities required by the packaged Prompt Template.

## Installation and Setup

After installing the Managed 2GP:

1. Assign the appropriate Compliance Reviewer Permission Set.
2. Confirm Prompt Builder / Einstein capabilities are available.
3. Create a `Compliance Agent Setting`.
4. Create the required `Compliance Agent Context` records.
5. Configure the required Field Sets.
6. Add the `complianceAgentReviewButton` LWC to the appropriate Lightning Record Page.
7. Confirm users can access the required Salesforce records and Files.

Compliance Reviewer operates on Salesforce records and Salesforce Files.

The application builds review context using Salesforce Platform data and invokes its packaged Prompt Template through Salesforce `ConnectApi`.

Compliance review results are persisted in Salesforce in `Compliance_Review__c`.
